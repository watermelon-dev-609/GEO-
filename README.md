# GEO生成式搜索优化系统 v2.2

**武汉微艺达智能科技有限公司** 定制开发 | 官网: http://www.weiyida.co

轻量化、零运维、纯白帽的生成式搜索优化平台。围绕生成式 AI 采信逻辑构建，通过逆向解析各大 AI 平台的检索机制、引用规则、排序偏好，自动生成 AI 更容易识别、理解、采信、推荐的内容，实现：**优先抓取 → 优先理解 → 优先引用 → 优先推荐**。

**v2.2 核心升级**：清洗规则独立开关、GEO优化规则按平台独立配置、转化追踪(UTM推广计划+Webhook上报+全链路漏斗)。

## 快速开始

### 环境要求

- Python 3.10+
- Node.js 18+
- 操作系统：Windows / macOS / Linux
- 内存：≥ 8GB（向量模型需 2-4GB）

### 1. 安装后端依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

编辑 `.env`，国内用户必设 `HF_MIRROR=https://hf-mirror.com`，Windows 用户必设 `KMP_DUPLICATE_LIB_OK=TRUE`。

### 3. 配置API Key

```bash
cp config/api_keys.yaml.example config/api_keys.yaml
```

编辑 `config/api_keys.yaml`，至少配置一个AI平台的API Key。

### 4. 启动后端服务

```bash
python run.py
```

后端启动后访问：http://127.0.0.1:8000/docs 查看 API 文档（22 模块、155+ 端点）

### 5. 安装并启动前端

```bash
cd frontend
npm install
npm run dev
```

前端启动后访问：http://localhost:5173

## 技术栈

- **后端**：Python FastAPI + Uvicorn + Pydantic v2 + APScheduler + httpx + BeautifulSoup4
- **前端**：Vue 3 + Vite 6 + Element Plus + Pinia + ECharts
- **LLM**：适配器工厂模式（10 平台 × 5 适配器），支持 OpenAI 兼容系 / Claude / 文心 / Ollama / LM Studio
- **向量**：sentence-transformers (bge-large-zh-v1.5) + FAISS
- **存储**：纯本地 JSON 文件系统 + YAML 配置模板，无数据库依赖
- **安全**：JWT 鉴权（3 级角色）、API Key 原子写入、审计日志（纯 ASGI）

## 核心技术壁垒

### 动态规则引擎（v2.1 核心变革）

平台优化规则从代码中解耦，改为 `data/platform_templates/` 下的 YAML 配置文件驱动：

```
之前：改规则 → 改 Python 代码 → 重启服务（数小时/天）
现在：改规则 → 编辑 YAML 文件 → 60秒缓存过期自动生效（分钟级）
```

每个平台模板包含结构化组件分解：Header（标题格式/首段规则/字数限制）、Body（H2密度/段落长度/FAQ数量）、Data（量化要求）、Schema（类型/字段映射）、Footer（标签/CTA限制）、Weights（内容源权重）、Verification（校验规则/禁词）。

### AI 采信六原则

| 原则 | 说明 |
|------|------|
| 实体锚定 | 企业、地域、产品名称清晰固定 |
| 定义优先 | 专业概念给出权威定义，AI 优先引用 |
| 量化事实 | 所有能力用数字支撑，提升可信度 |
| FAQ 结构 | 内置问答对，适配对话式检索 |
| 层级结构化 | H2/H3 / 列表降低 AI 解析成本 |
| 信息增量 | 提供本地化、行业专属稀缺信息 |

### 8 维防幻觉评测体系

| 维度 | 权重 | 说明 |
|------|------|------|
| 品牌召回率 | 20 | 品牌信息被 AI 搜索匹配的概率 |
| 方案匹配度 | 20 | 内容与用户搜索意图的语义相关性 |
| 优势采信率 | 15 | 核心优势被 AI 回答引用的可能性 |
| 真实引用率 | 15 | 实际被引用的内容比例 |
| 结构质量 | 10 | 内容组织与可读性 |
| 差异化程度 | 10 | 与竞品的区分度 |
| 信源一致性 | 10 | 输出与输入的一致性（防幻觉门禁，<30 分硬上限 50） |
| E-E-A-T 权威度 | — | Experience/Expertise/Authoritativeness/Trustworthiness |

### 规则感知与自动化闭环（v2.1 新增）

```
RSS监控(7信源) ────→ 关键词告警
AI采信测试(26问×5平台) ──→ 行为分析 ──→ 每周结构变化报告
                                        ↓
                         模板引擎(YAML) ← 结构调整建议
                               ↓
                    适配流水线(扫描→重生成→灰度→全量)
                               ↓
                    数据闭环(采信率验证→迭代)
```
