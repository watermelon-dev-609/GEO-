## 系统登录

### 首次使用

系统启动后，访问 http://localhost:5173 进入登录页（LoginView）。

- **默认管理员密码**：`admin`（可在 `config/settings.yaml` 的 `auth` 段修改）
- 登录后获取 JWT Token，后续 API 请求自动携带鉴权信息
- 支持管理员/编辑/查看三级角色权限

## 核心流水线（4 步）

### 第一步：文案导入与智能清洗

导航至"文案导入"（ImportView）。

**导入方式：**
- **文本粘贴**：直接粘贴企业文案、产品介绍、案例描述
- **文件上传**：支持 .txt / .md / .docx / .xlsx 文件

**操作流程：**
1. 选择或自动识别沙盘业务类型（8 类可选）
2. 点击"清洗设置"齿轮按钮，可独立开关每条清洗规则
3. 点击"开始智能清洗"

**清洗规则设置（可独立开关）：**
| 规则 | 说明 | 默认 |
|------|------|------|
| 去除冗余 | 删除重复内容、空话套话、无意义的修饰词 | ✅ 启用 |
| 术语统一 | 将口语化表达规范为行业标准术语 | ✅ 启用 |
| 格式标准化 | 统一段落结构，确保逻辑清晰、层次分明 | ✅ 启用 |
| 保留关键信息 | 产品参数、技术指标、服务流程、案例数据完整保留 | ✅ 启用 |
| 去广告化 | 去除过度营销用语，保留客观描述 | ✅ 启用 |

**系统自动完成：**
- 根据启用的规则进行标准化清洗
- 提取五维关键信息（核心优势 / 适用场景 / 技术特点 / 服务能力 / 落地价值）

清洗后展示**清洗前后对比**和**五维信息提取结果**。规则变更即时生效，清洗结果自动缓存。

### 第二步：GEO 智能优化

导航至"GEO优化工坊"（GEOWorkshop）。

1. 确认沙盘业务类型和清洗后的文案
2. 勾选目标 AI 平台（支持多选，并行生成）
3. 点击"优化规则设置"可**按平台独立开关**优化规则
4. 点击"开始GEO优化"

**优化规则设置（按平台独立配置）：**

| 平台 | 可选规则 |
|------|---------|
| **DeepSeek** | RAG切片优化、FAQ结构强化、参数标准化、品牌实体锚定、数据原词保留 |
| **豆包** | 短句硬约束(≤30字)、利益前置、通俗表达、行动指引收尾 |
| **文心一言** | 标题硬格式、首段四要素、关键词密度优化、资质背书前置 |
| **通义千问** | 三层递进结构、方案逻辑闭环、B端政企导向、交付保障体系 |
| **Kimi** | 四层递进论证、高信息密度、实体原词优先、长文深度展开 |

每条规则可独立开关，切换即时保存到 `settings.yaml`。生成文案时仅应用已启用的规则。

**9 大平台独立优化策略（2026年6月更新）：**

| 平台 | 优化策略 | 内容源权重 | 结构要点 | 适用场景 |

### 第三步：AI 效果评测

导航至"AI评测中心"（EvaluationCenter）。

1. 选择要评测的文案（自动带入优化结果）
2. 选择模拟用户角色（4 类）：
   - **B端政企采购**：关注资质、案例、交付能力
   - **技术人员选型**：关注技术参数、工艺精度
   - **项目经办人**：关注价格、流程、本地服务
   - **普通咨询用户**：关注厂家推荐、口碑
3. 可选：添加自定义评测问题
4. 点击"开始评测"

**7 维评测体系：**

| 维度 | 权重 | 说明 |
|------|------|------|
| 品牌召回率 | 20 | 品牌信息被 AI 搜索匹配的概率 |
| 方案匹配度 | 20 | 内容与用户搜索意图的语义相关性 |
| 优势采信率 | 15 | 核心优势被 AI 回答引用的可能性 |
| 真实引用率 | 15 | 实际被引用的内容比例 |
| 结构质量 | 10 | 内容组织与可读性 |
| 差异化程度 | 10 | 与竞品的区分度 |
| 信源一致性 | 10 | 输出与输入内容的一致性（防幻觉6层防线核心门禁） |

**评测结果包含：**
- 综合评分（0-100 分），信源一致性 < 30 硬上限 50 分
- 优化前后对比（含原始文案）
- 各平台 / 各维度评分详情
- 内容短板诊断
- 迭代优化建议

**SSE 流式评测**：7 维独立并发评测，实时展示各维度进度。

## 转化追踪（v2.2 新增）🆕

追踪 GEO 优化从 AI 曝光到最终转化的全链路效果。

### 核心原理

```
AI平台引用你的内容 → 用户点击链接 → 进入官网 → 提交表单/咨询 → 归因到具体AI平台
```

### 落地页配置

系统默认落地页：**http://www.weiyida.co**（在 `config/settings.yaml` → `system.enterprise_website` 配置）

### UTM 推广计划

导航至"UTM推广计划管理"（UTMCampaignManager）：

1. 创建推广计划：填写计划名称，落地页URL自动填入官网地址
2. 系统自动为每个 AI 平台生成带 UTM 追踪参数的链接：
   - `http://www.weiyida.co/xxx?utm_source=deepseek&utm_medium=ai_referral`
   - `http://www.weiyida.co/xxx?utm_source=doubao&utm_medium=ai_referral`
   - …等 10 个平台
3. 将带 UTM 的链接发布到官网对应页面
4. AI 引用点击 → UTM 参数标记来源平台 → 归因分析

### 转化事件上报

通过 Webhook 上报转化事件（表单提交、电话咨询等）：

```
POST /api/conversions/event
{
  "type": "form_submit",
  "value": 5000,
  "landing_page": "http://www.weiyida.co/solutions/smart-traffic",
  "referrer": "?utm_source=deepseek&utm_medium=ai_referral"
}
```

### 全链路漏斗

四阶段漏斗自动计算：
| 阶段 | 数据来源 | 说明 |
|------|---------|------|
| AI曝光量 | AI采信测试（自动估算） | 内容在各 AI 平台的曝光次数 |
| AI引用量 | AI采信测试（自动统计） | 内容被 AI 实际引用的次数 |
| 网站访问量 | GA4/百度统计(可选) | AI 来源的网站访问量 |
| 转化量 | Webhook上报 | AI 来源的实际转化数 |

### 接入真实数据（可选）

- **GA4**：配置服务账号凭据和 property_id → `data/traffic/config.json`
- **百度统计**：配置 api_key、secret_key、site_id → `data/traffic/config.json`
- **转化Webhook**：在你的表单/客服系统中调用 `POST /api/conversions/event`

不接外部数据源时，UTM 链接生成和 AI 漏斗估算仍可正常使用。

## 模板引擎（v2.1 新增 — 核心变革）

导航至"模板引擎"（TemplateEngine），可视化管理所有 AI 平台的优化规则。

> **之前**：改平台规则 → 改 Python 代码 → 重启服务（数小时/天）
> **现在**：改平台规则 → 编辑 YAML 配置 → 60 秒自动生效（分钟级）

### 平台模板编辑
- 左侧选择目标 AI 平台（11 个可选）
- 中间分 7 个 Tab 编辑模板组件：
  - **概览**：平台名称、版本、策略、引用机制、风格
  - **Header**：标题格式、首段规则、字数范围
  - **Body**：H2密度、段落长度、FAQ数量、特殊规则
  - **Schema**：优先Schema类型、官网额外类型
  - **Weights**：内容源权重（如百家号:9、知乎:4）
  - **验证**：校验规则、平台禁词、禁忌模式
  - **Rules**：Prompt规则列表（完全兼容旧格式）

### 版本管理
- 每次保存自动创建历史版本
- 右侧面板查看版本时间线
- 支持版本 Diff 对比（差异高亮）
- 支持一键回滚到任意历史版本

### 结构预览
- 右侧面板实时预览基于当前模板生成的内容结构
- 展示：标题格式、字数范围、H2密度、FAQ数量、Schema类型、内容源权重、禁词列表

### 缓存刷新
- 保存模板后自动刷新 60 秒 TTL 缓存
- 也可手动点击"刷新缓存"立即生效
- 平台规则配置存储在 `data/platform_templates/{platform}.yaml`

## 适配流水线（v2.1 新增）

导航至"适配流水线"（AdaptationPipeline），当平台规则变化时，自动化完成从扫描到发布的全流程。

### 11 阶段流水线

```
监控发现变化 → 结构调整需求 → 模板已更新 →
存量扫描 → 内容重生成 → 自动校验 →
人工抽检(5%) → 灰度发布(10%) → 全量发布(100%) →
3天发布后测试 → 7天发布后测试
```

### 操作流程
1. 选择平台 → 点击"创建适配运行"
2. 依次推进各阶段（或点击"扫描存量"直接跳到扫描）
3. "灰度10%"先发布小部分内容，观察 AI 引用变化
4. 确认无误后"全量发布"
5. 异常时点击"回滚"一键恢复旧模板

### Kanban 视图
- 每个适配运行以卡片展示
- 左侧色条标识状态：蓝色=进行中 / 绿色=已完成 / 红色=已回滚
- 步骤条实时展示当前所处阶段

## 数据闭环（v2.1 新增）

导航至"数据闭环"（FeedbackDashboard），用数据验证优化效果，驱动迭代决策。

### 核心指标
| 指标 | 说明 |
|------|------|
| **AI 采信率** | 内容在 5 大 AI 中的被引用次数 / 总检索次数 |
| **结构命中率** | 新模板内容被 AI 引用时，匹配预期结构特征的比例 |
| **时效衰减率** | 内容发布后 7/15/30/90 天的引用率下降幅度 |
| **违规拒采率** | 因广告/堆砌/虚假数据被 AI 拒采的比例 |

### 趋势分析
- 采信率 12 周趋势折线图（按平台）
- 时效衰减曲线（豆包 15 天黄金期 vs DeepSeek 长文持久性）
- 异常告警面板：自动检测采信率显著下降

### 自动诊断
- 点击"运行诊断" → 系统自动：
  1. 检测采信率是否下降
  2. 回溯本周监控报告找可能原因
  3. 定位具体结构问题（如 FAQ 不足、段落过长）
  4. 生成迭代建议和行动步骤

### 迭代闭环
```
采信率下降 → 诊断定位问题 → 更新模板配置 →
适配流水线重生成 → 灰度发布 → 验证采信率回升
```

## 使用技巧

1. **先小后大**：先用少量文案测试各平台效果，确认满意后再批量处理
2. **多平台并行**：一次选择多个平台，同步生成对比效果
3. **迭代优化**：根据评测结果的短板诊断，修改原始文案后重新优化
4. **定期更新**：AI 平台算法会更新，建议通过定时任务每季度自动重新优化核心文案
5. **缓存利用**：相同文案 + 相同平台的结果会被缓存（MD5 键），二次调用秒级返回
6. **批量提速**：大量文案用批量处理页面，SSE 流式返回避免超时
7. **离线运行**：配置 Ollama/LM Studio 后可在完全离线环境使用全部功能
8. **版本管理**：重要优化结果存档，便于回溯和对比
9. **热更新规则（v2.1）**：平台规则变化时，编辑 YAML 模板配置即可，无需改代码、无需重启
10. **灰度发布（v2.1）**：规则大变时，先灰度 10% 观察效果，确认无误再全量，避免一次改崩所有平台收录
11. **数据驱动（v2.1）**：关注数据闭环仪表盘，及时发现采信率下降并自动诊断
