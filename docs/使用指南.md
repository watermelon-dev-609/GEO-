# GEO系统使用指南

## 完整操作流程

### 第一步：配置检查

进入系统后，点击右上角"配置检查"确认AI平台配置状态。绿色表示已配置可用，灰色表示待配置。

### 第二步：文案导入与清洗

1. 导航到"文案导入"页面
2. 选择导入方式：
   - **文本粘贴**：直接粘贴企业文案、产品介绍、案例描述
   - **文件上传**：上传 .txt / .md / .docx / .xlsx 文件
3. 可选：手动选择沙盘业务类型（不选则自动识别）
4. 点击"开始智能清洗"

系统会自动完成：
- 去除冗余、重复内容
- 统一行业专业术语
- 格式标准化
- 提取五维关键信息（核心优势/适用场景/技术特点/服务能力/落地价值）

清洗后会展示清洗前后对比和五维信息提取结果。

### 第三步：GEO智能优化

1. 导航到"GEO优化工坊"
2. 确认沙盘业务类型和清洗后的文案
3. 勾选目标AI平台（支持多选，并行生成）
4. 点击"开始GEO优化"

系统针对每个平台独立生成优化文案：
- **文心一言版**：关键词精准、地域明确、资质前置，适配百度AI卡片收录
- **通义千问版**：方案思维、行业适配、逻辑闭环，适配B端选型
- **GPT版**：隐性结构化框架、维度清晰、段落独立，适配AI总结对比
- **Claude版**：细节饱满、逻辑严谨、深度还原，适配长文本专业采信
- **DeepSeek版**：技术参数量化、工艺详细、工程思维，适配技术选型
- **豆包版**：短句通俗、亮点前置、直白获客，适配大众AI推荐
- **元宝版**：正规严谨、流程清晰、资质背书，适配政企供应商筛选

每个平台结果附有优化策略说明，解释做了哪些针对性的调整。

### 第四步：AI效果评测

1. 导航到"AI评测中心"
2. 选择要评测的文案（自动带入优化结果）
3. 选择模拟用户角色：
   - B端政企采购：关注资质、案例、交付能力
   - 技术人员选型：关注技术参数、工艺精度
   - 项目经办人：关注价格、流程、本地服务
   - 普通咨询用户：关注厂家推荐、口碑
4. 可选：添加自定义评测问题
5. 点击"开始评测"

系统将从三个维度评测：
- **品牌召回率**：品牌信息被AI搜索匹配的概率
- **方案匹配度**：内容与用户搜索意图的语义相关性
- **优势采信率**：核心优势被AI回答引用的可能性

评测结果包含：
- 综合评分（0-100分）
- 优化前后对比（如有原始文案）
- 各平台评分详情
- 内容短板诊断
- 迭代优化建议

### 第五步：成果导出

1. 导航到"成果导出"
2. 选择导出内容：
   - 优化文案（.md / .docx）
   - JSON-LD结构化代码
   - 评测报告（.html / .pdf）
3. 填写企业信息（用于JSON-LD生成）
4. 点击"一键导出"

## 八个沙盘业务类型的优化要点

### 智慧交通/城市/工业/农业/物流沙盘
重点突出：数字化仿真、动态联动、物联网场景适配、政企项目落地能力、行业解决方案价值。

### 军事地形沙盘
重点突出：地形精准还原、比例标准化、战术场景仿真、科研教学适配、合规保密特性、专业演示价值。

### 数字多媒体沙盘
重点突出：触控交互、声光电动态特效、智能演示、展厅视觉呈现、数字化体验优势。

### 地产/规划/展厅沙盘
重点突出：城市空间还原、项目规划展示、政企汇报适配、品牌展厅落地、项目公示场景。

## 使用技巧

1. **先小后大**：先用少量文案测试各平台效果，确认满意后再批量处理
2. **多平台并行**：一次选择多个平台，同步生成对比效果
3. **迭代优化**：根据评测结果的短板诊断，修改原始文案后重新优化
4. **定期更新**：AI平台算法会更新，建议每季度重新优化一次核心文案
5. **缓存利用**：相同文案+相同平台的结果会被缓存，二次调用秒级返回
