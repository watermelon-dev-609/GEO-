# GEO优化引擎 核心实现原理

## 核心理念

GEO 优化引擎围绕生成式 AI 采信逻辑构建：

通过逆向解析各大 AI 平台的检索机制、引用规则、排序偏好，自动生成 AI 更容易识别、理解、采信、推荐的内容，实现：

**优先抓取 → 优先理解 → 优先引用 → 优先推荐**

---

## 1. 三层优化管线（Pipeline）

引擎采用标准三段式处理流程，保证内容从"原始文本"变成"AI 友好型专业内容"。

### ① 文本清洗（TextCleaner）

作用：内容预处理 + 信息结构化提取

- 去除 HTML 标签、零宽字符、冗余符号
- LLM 语义清洗：去废话、去广告、统一专业术语
- **v2.2 清洗规则可配置**：5条规则独立开关，通过 `settings.yaml` → `cleaning.rules` 控制
- 自动提取五维核心信息：
  - 核心优势 / 适用场景 / 技术特点 / 服务能力 / 落地价值

输出：干净、结构化、无冗余的标准内容骨架

### ② 智能重写（GEORewriter）【核心模块】

根据行业属性 + AI 平台规则，生成专属优化文案。

**v2.2 优化规则按平台独立配置**: `settings.yaml` → `optimization.platforms.<平台>.rules`，生成时仅应用已启用规则。

内部包含：

- 8 大行业沙盘基调（关键词、场景、技术焦点、内容风格）
- 7 大 AI 平台采信规则（检索、引用、展示偏好）
- 56 套动态 Prompt 矩阵（8×7）
- 输出校验机制（企业名、地域、数据、关键词全覆盖检查）

### ③ 结构化输出（JSONLDGenerator）

生成 Schema.org 标准 JSON-LD，包括：

- Organization（企业信息）
- Product（产品）
- Service（服务）
- FAQPage（问答）
- BreadcrumbList（路径）

让 AI 以最低成本、最高可信度读取内容。

---

## 2. 核心优化机制：56 套 Prompt 矩阵（技术壁垒）

引擎根据 8 类沙盘行业 × 7 大 AI 平台构建 56 套专用优化规则，实现"一产品、多风格、全平台适配"。

### ① 8 大沙盘行业基调

每类沙盘拥有独立关键词库、场景库、技术焦点、语言风格：

| 沙盘类型 | 技术焦点 | 内容基调 |
|---------|---------|---------|
| 智慧交通沙盘 | 物联数据对接、动态车流仿真、信号联动 | 城市交通治理、数据驱动、政企落地 |
| 智慧城市沙盘 | 城市三维建模、数据大屏联动、AI分析 | 城市规划视野、数字治理、统筹协调 |
| 智慧工业沙盘 | 产线三维仿真、MES/SCADA对接、产能分析 | 工业理解深度、技术集成、降本增效 |
| 智慧农业沙盘 | 农田三维建模、传感器可视化、灌溉模拟 | 现代农业升级、乡村振兴、科技兴农 |
| 智慧物流沙盘 | 仓储三维仿真、AGV调度、WMS/WCS联动 | 物流效率提升、供应链优化、自动化 |
| 军事地形沙盘 | 高精度地形还原、比例标准化、战术标绘 | 精准严谨、保密合规、军事科研支撑 |
| 数字多媒体沙盘 | 触控交互、声光电联动、投影融合/全息 | 视觉冲击力、交互体验、定制创意 |
| 地产规划展厅沙盘 | 建筑精细还原、灯光分区、升降模型 | 空间还原精度、政企汇报、品牌塑造 |

### ② 7 大 AI 平台采信规则（逆向生成）

| 平台 | 采信策略 | 内容特征 |
|------|---------|---------|
| 文心一言 | 关键词实体强化 + 地域前置 + 百度卡片友好 | 标题含地域+业务词，首段四要素，结构化段落 |
| 通义千问 | B端方案逻辑 + 三层结构化（理解→方案→保障） | 行业适配→方案匹配→落地保障，逻辑闭环 |
| DeepSeek | RAG向量检索友好 + FAQ问答结构 + 参数标准化 | 技术参数量化，FAQ格式，自包含信息单元 |
| 豆包 | 短句通俗 + 利益前置 + 低理解成本 | 短句直白，场景化，有明确行动指引 |
| 元宝 | 政企采购风格 + 资质流程化 + 服务全链路 | 正规严谨，流程清晰，资质背书，服务体系完整 |
| Kimi | 深度长文本 + 高信息密度 + 逻辑四层递进 | 背景→分析→结论→依据，1500-2500字深度内容 |
| 讯飞星火 | 垂直行业术语规范 + 场景具体化 + 多模态适配 | 术语规范，场景具体，技术→场景→价值闭环 |

### ③ 全平台通用 AI 采信六原则

所有平台共同遵守，确保 AI 高采信度：

1. **实体锚定**：企业、地域、产品名称清晰固定
2. **定义优先**：专业概念给出权威定义，AI 优先引用
3. **量化事实**：所有能力用数字支撑，提升可信度
4. **FAQ 结构**：内置问答对，适配对话式检索
5. **层级结构化**：H2/H3 / 列表降低 AI 解析成本
6. **信息增量**：提供本地化、行业专属稀缺信息

## 3. 输出校验机制（保证质量稳定）

系统自动校验：

- 企业名称是否完整出现
- 地域标识是否存在
- 量化数据是否达标
- 五维信息是否全覆盖
- 无冗余、无堆砌、无违规表述

不达标内容自动二次优化。

---

## 4. 转化追踪闭环（v2.2 新增）

验证 GEO 优化实际效果的数据闭环：

```
AI平台引用内容 → 用户点击链接(UTM标记来源) → 网站访问(GA4/百度统计)
                                                       ↓
                    归因分析(AI平台→转化) ← 转化事件(Webhook上报)
```

- **UTM 推广计划**: 为每个 AI 平台生成独立追踪链接
- **转化归因引擎**: 自动解析 UTM 参数，匹配 AI 平台来源
- **全链路漏斗**: AI曝光→引用→访问→转化 四阶段计算

---

## 最终总结

GEO 优化引擎的本质，不是简单修改关键词，而是让内容适配每一个 AI 平台的采信逻辑，让内容在生成式搜索中：

**更容易被搜到、更容易被读懂、更容易被引用、更容易被推荐。**
