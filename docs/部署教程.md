# GEO系统本地部署教程（零基础版）

## 一、环境准备

### 1. 安装 Python

访问 https://www.python.org/downloads/ 下载 Python 3.10 或更高版本。

安装时勾选 **"Add Python to PATH"**（添加到系统环境变量）。

安装完成后，打开命令提示符（Win+R 输入 cmd），验证：

```cmd
python --version
```

应显示 Python 3.10.x 或更高版本。

### 2. 安装 Node.js

访问 https://nodejs.org/ 下载 LTS 版本（推荐 18.x 或 20.x）。

安装完成后验证：

```cmd
node --version
npm --version
```

---

## 二、后端部署

### 1. 进入项目目录

```cmd
cd geo-optimizer\backend
```

### 2. 安装 Python 依赖

```cmd
pip install -r requirements.txt
```

> 注意：如果下载速度慢，可以使用国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

安装时间约 5-15 分钟，取决于网络速度。sentence-transformers 首次运行时会自动下载模型（约 1.3GB），请耐心等待。

### 3. 配置 API Key

复制示例配置文件：

```cmd
copy config\api_keys.yaml.example config\api_keys.yaml
```

用记事本打开 `config\api_keys.yaml`，填入您的 API Key。

### 4. 启动后端

```cmd
python run.py
```

看到以下信息表示启动成功：

```
Uvicorn running on http://127.0.0.1:8000
```

浏览器访问 http://127.0.0.1:8000/docs 可以看到 API 文档页面。

## 三、前端部署

### 1. 新开一个命令提示符，进入前端目录

```cmd
cd geo-optimizer\frontend
```

### 2. 安装依赖

```cmd
npm install
```

### 3. 启动前端

```cmd
npm run dev
```

看到以下信息表示启动成功：

```
VITE v6.x.x  ready in xxx ms
➜  Local:   http://localhost:5173/
```

浏览器访问 http://localhost:5173 即可使用系统。

## 四、常见问题

### Q: pip install 报错或很慢？
A: 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### Q: 启动后端报错 "No module named 'xxx'"？
A: 依赖未完全安装，重新运行 `pip install -r requirements.txt`

### Q: 前端页面打开但数据显示不出来？
A: 检查后端是否已启动（http://127.0.0.1:8000/docs 能否访问）

### Q: 点击"开始优化"报错 "未配置API Key"？
A: 检查 `config/api_keys.yaml` 中是否已填入有效的 API Key（不是 "your-xxx-here"）

### Q: Embedding模型下载失败？
A: 首次使用需要下载 bge-large-zh 模型（约1.3GB），确保网络通畅。也可以手动下载放到 `data/cache/models/` 目录。

### Q: 内存不足？
A: 编辑 `config/settings.yaml`，将 `embedding.device` 设为 `cpu`，并减少 `batch_size` 到 4。
