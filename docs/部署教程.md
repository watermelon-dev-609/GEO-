# GEO系统本地部署教程（v2.2）

> 适用于 v2.2 Personal 版本，覆盖全部 11 大 AI 平台 × 8 类沙盘业务

## 一、环境准备

### 1. 安装 Python

访问 https://www.python.org/downloads/ 下载 Python 3.10 或更高版本。

安装时勾选 **"Add Python to PATH"**（添加到系统环境变量）。

安装完成后，打开命令提示符（Win+R 输入 cmd），验证：

```cmd
python --version
```

应显示 Python 3.10.x 或更高版本。

### 2. 安装 Node.js

访问 https://nodejs.org/ 下载 LTS 版本（推荐 18.x 或 20.x）。

安装完成后验证：

```cmd
node --version
npm --version
```

## 二、后端部署

### 1. 进入项目目录

```cmd
cd geo-optimizer\backend
```

### 2. 配置环境变量（重要）

复制示例环境变量文件：

```cmd
copy .env.example .env
```

在 `.env` 中设置以下必需变量：

| 变量 | 说明 | 必填 |
|------|------|------|
| `HF_MIRROR` | HuggingFace 镜像地址，国内必设为 `https://hf-mirror.com` | 国内必填 |
| `KMP_DUPLICATE_LIB_OK` | Windows 下必设为 `TRUE`，防止 PyTorch 与 scikit-learn DLL 冲突 | Windows 必填 |

`.env` 示例：

```env
HF_MIRROR=https://hf-mirror.com
KMP_DUPLICATE_LIB_OK=TRUE
```

### 3. 安装 Python 依赖

```cmd
pip install -r requirements.txt
```

> 注意：如果下载速度慢，可以使用国内镜像：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

安装时间约 5-15 分钟，取决于网络速度。sentence-transformers 首次运行时会自动下载模型（bge-large-zh，约 1.3GB），请耐心等待。

### 4. 配置 API Key

复制示例配置文件：

```cmd
copy config\api_keys.yaml.example config\api_keys.yaml
```

用记事本打开 `config\api_keys.yaml`，填入您的 API Key。系统支持 `${VAR}` 占位符引用 `.env` 中的环境变量。

### 5. 启动后端

```cmd
python run.py
```

启动过程会自动完成：
- 预加载 Embedding 向量模型（首次约 1.3GB 下载）
- 加载评测历史记录
- 启动定时任务调度器（APScheduler）
- 初始化 9 大平台规则数据

看到以下信息表示启动成功：

```
Uvicorn running on http://127.0.0.1:8000
```

浏览器访问 http://127.0.0.1:8000/docs 可以看到完整的 19 模块 API 文档页面。

## 四、可选：本地LLM部署（完全离线运行）

### Ollama 方式

1. 下载安装 Ollama：https://ollama.com/
2. 拉取模型：`ollama pull qwen2.5:7b`（或其他模型）
3. 在 `config/api_keys.yaml` 中配置 ollama 平台，base_url 指向 `http://localhost:11434`

### LM Studio 方式

1. 下载安装 LM Studio：https://lmstudio.ai/
2. 下载并加载模型，启动本地服务器
3. 在 `config/api_keys.yaml` 中配置 lmstudio 平台，base_url 指向 `http://localhost:1234`

## 五、常见问题

### Q: pip install 报错或很慢？
A: 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### Q: 启动后端报错 "No module named 'xxx'"？
A: 依赖未完全安装，重新运行 `pip install -r requirements.txt`

### Q: 前端页面打开但数据显示不出来？
A: 检查后端是否已启动（http://127.0.0.1:8000/docs 能否访问）

### Q: 点击"开始优化"报错 "未配置API Key"？
A: 检查 `config/api_keys.yaml` 中是否已填入有效的 API Key（不是 "your-xxx-here"）

### Q: Embedding模型下载失败？
A: 首次使用需要下载 bge-large-zh 模型（约1.3GB），请确认已设置 `HF_MIRROR=https://hf-mirror.com`。也可以手动下载放到 `data/cache/models/` 目录。

### Q: Windows 下启动后端崩溃/闪退？
A: 确认 `.env` 中已设置 `KMP_DUPLICATE_LIB_OK=TRUE`，这是 Windows 必须的环境变量。

### Q: 内存不足？
A: 编辑 `config/settings.yaml`，将 `embedding.device` 设为 `cpu`，并减少 `batch_size` 到 4。

### Q: 如何配置用户登录密码？
A: 编辑 `config/settings.yaml` 中的 `auth` 配置段，设置管理员密码。首次使用默认密码为 `admin`。

### Q: 定时任务不执行？
A: 检查后端是否正常运行。定时任务依赖 APScheduler，进程重启后持久化任务会从 `data/scheduler_jobs.json` 自动恢复。

## 七、系统架构速览

```
geo-optimizer/
├── backend/
│   ├── app/
│   │   ├── main.py              # FastAPI 入口，19 路由前缀，4 startup 事件
│   │   ├── api/                  # 19 个路由模块
│   │   ├── core/                 # 20+ 业务引擎模块
│   │   ├── models/               # 数据模型（enums / schemas）
│   │   ├── services/             # 服务层（LLM 适配器工厂 / Embedding）
│   │   ├── prompts/              # Prompt 模板矩阵
│   │   └── utils/                # 工具（配置 / 缓存 / 重试 / 错误码）
│   ├── config/                   # 配置文件（settings.yaml / api_keys.yaml）
│   ├── data/                     # 运行时数据（JSON 文件存储，无数据库）
│   ├── .env                      # 环境变量
│   └── requirements.txt
├── frontend/
│   ├── src/
│   │   ├── views/                # 14 个页面组件
│   │   ├── components/           # 9 个通用组件
│   │   ├── api/                  # Axios 实例 + SSE 工厂
│   │   ├── stores/               # Pinia 状态管理
│   │   └── router/               # 懒加载路由
│   └── package.json
└── docs/                         # 项目文档
    ├── 部署教程.md
    ├── 使用指南.md
    └── 企业扩容方案.md
```
